Stacked on strategy candidate ce4b659a2b80067fc6f947c87e5a7258219d5ba7 (#14). Synthetic prototype local Godot 4.7.2 ed1daf0bf 19/19 checks PASS, to be confirmed by exact-head lab CI. Sector measurement interpolates actual crossings at 200ms, accepts positive/negative time deltas and excludes partial/exempt sections. Reference sector speeds are provided by caller, not surveyed FIA data, and tolerance/repeated crossing rule is an illustrative game rule only. Review statuses DISMISSED, REVIEW, CONFIRMED, INCONCLUSIVE; no automatic penalties or classification changes. Swept axis-aligned footprint in a local track frame handles longitudinal/lateral overlap, wrap and lapped proximity. It is not a collision response solver, omits orientation, track width, elevation, body rotation, impulse/damage and physical lateral trajectory. Floating-point test laboratory only; no cross-platform sporting determinism claim. Before integration require validated sector definitions, active VSC scenario, stored/replayable review evidence, exemption semantics, and physical trajectory/solver design. No duplicate live kernel.
